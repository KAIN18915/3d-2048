How to Play

Move tiles on the active layer using arrow keys or WASD.
↑↓←→ or W A S D — move tiles on active layer
Q / E — move tiles between layers (Up / Down)
Z / X — change active layer view
R — rotate view
N — new game

Combine same numbers to reach 2048... and beyond! Tiles can move across all 4 layers in 3D!
